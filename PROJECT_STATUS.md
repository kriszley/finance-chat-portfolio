# Project status

This is an in-progress side project and portfolio snapshot, not a production financial product.

## Implemented

- Next.js chat and chart interface
- FastAPI tool-execution API with SQLite persistence
- Scotiabank and BMO CSV parsers
- Normalize, deduplicate, transfer-detection, categorization, and reporting pipeline
- Rules-first categorization with optional cloud-LLM fallback
- Synthetic demo data and deterministic Python tests

## Planned

- Authentication and encrypted per-user storage before any hosted deployment
- Additional bank parsers
- Better local-only, non-cloud natural-language mode
- Browser-level end-to-end tests
- Accessibility and error-state polish
